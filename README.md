# Joseph Siew landing page

A single landing page for Joseph Siew Financial Advisory, built on the Pactum Framer template as a static HTML/CSS/JS rebuild.

- `site/` is the finished page and is what GitHub Pages serves (from the `gh-pages` branch).
- `build/` is the generator. Run `python3 build/build.py` to rebuild `site/index.html`.
- `BUILD-NOTES.md` covers the section mapping, verification and deviations.
